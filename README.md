# 💬 AI Chat App

A full-stack real-time chat application with integrated AI features to enhance user experience. Built for seamless communication, the app combines real-time messaging with smart AI replies, authentication, and a modern responsive UI.

---

## 🚀 Features

- 🔄 **Real-time Messaging** – Powered by Socket.io for instant message exchange between users.
- 🤖 **AI Assistant Integration** – Offers smart auto-replies and conversation summaries to enhance interactions.
- 🔐 **Secure Authentication** – JWT-based login system to ensure safe and authorized access.
- 🖌️ **Modern UI** – Responsive, clean interface built with Tailwind CSS for a smooth user experience.

---

## 🛠 Tech Stack

### Frontend:
- React
- Tailwind CSS
- Socket.io Client

### Backend:
- Node.js
- Express.js
- Socket.io Server
- JWT Authentication

### AI:
- Google Gemini 2.0
